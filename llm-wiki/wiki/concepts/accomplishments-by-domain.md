# Accomplishments by Domain

> **Doc type:** reference · router
>
> High-level orientation of what the owner has accomplished, grouped by domain. This is the **landing page for ingested brag entries** and the **pool the primary resume draws from** — not a resume itself. Each bullet is a headline with a citation; depth lives in the cited source. Audience: the owner deciding what to promote; agents ingesting brag entries or drafting resume text.
>
> **This page is a router.** The bullets live in five shards beside it, grouped by subject. Read this page, then only the shard that holds the domain in hand. Split 2026-09-25, when the single page had reached 72 KB against a 25 KB on-demand budget.

## How to use this page

- **Ingest:** for each domain the brag entry lists in its `domains:` frontmatter, find the shard below and add or strengthen a bullet under that domain's heading; cite the entry file. Keep bullets to one or two sentences; do not paste the entry. A ledger row still names this page and the domain in italics, e.g. `accomplishments-by-domain.md (*Positioning and location*)`; the table resolves it.
- **Promote:** pick bullets whose weight justifies a place in the resume at the intended cut level ([primary-resume.md](../resume/primary-resume.md)); write the resume text through [update-workflow.md](../resume/update-workflow.md).
- **Grow:** the table grows with **shards**, not bullets. When a shard nears 25 KB, split it by domain and add rows here; when a single domain exceeds ~15 bullets and has a coherent sub-theme, give it its own page under `concepts/` and a one-line pointer in its shard. A new domain is a new row, placed in the shard whose subject it shares.
